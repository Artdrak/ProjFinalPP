# Reserva de Laboratórios e Salas de Aula
Entrega parcial 1: cadastros de Usuários, Laboratórios, Salas e Status.

**Stack:** Node.js (Express + mssql) · Next.js (React) · SQL Server

## Como rodar
1. Execute `banco/script.sql` no SQL Server (SSMS).
2. `cd backend` → copie `.env.example` para `.env` e ajuste usuário/senha → `npm install` → `npm start` (porta 3001).
3. `cd frontend` → `npm install` → `npm run dev` → http://localhost:3000
